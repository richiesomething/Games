How Parlor works
  • Set up once. Enter everyone's names above and choose individuals or teams of two. Every game uses that list.
  • One phone. Every game is pass-and-play. Screens that hide secrets ask you to hand the phone over first.
  • Game-night standings. When a game ends, sides earn night points by placement: 5 for 1st, 3 for 2nd, 2 for 3rd, 1 for 4th. Points go to each player, so you can reshuffle teams between games.
  • No repeats. Each game remembers which cards this device has dealt and works through the whole pool before repeating.
  • Pen and paper help for Categories, Common Thread and Fictionary. Some games also let you type on the phone.
  • Tip: use "Add to Home Screen" to run it full-screen like an app.
